# jl2ml.github.io

Academic website for Jiayi Li, published with GitHub Pages.

The site is intentionally dependency-free: each page is plain semantic HTML and shares the styles in `site.css`. To preview locally, run `python3 -m http.server` from the repository root and open the displayed localhost URL.

## Content map

- `index.html` — homepage, selected work, and current news
- `research.html` — research agenda and project context
- `publications.html` — publication record
- `teaching.html` — teaching and mentoring
- `service.html` — talks, organization, and service
- `bio.html` — reusable short biography and portrait
- `misc.html` — personal page

Update dates appear in page footers. The CV is maintained separately as `cv.pdf`.
